# COS10005 Web Development - Week 10 Lab (jQuery)
---

## Lab Overview
This project demonstrates the use of **jQuery** and JavaScript to enhance user interaction on web forms[cite: 9]. It covers:
1. **Client-Side Form Validation:** Validating inputs (User ID format, matching passwords, non-empty checks, and name regular expressions) using jQuery selectors[cite: 9, 10, 11].
2. **Section Collapse/Expand Effect:** Toggling visibility of form sections (`[-]` / `[+]`) using jQuery animation (`slideToggle`)[cite: 9, 12, 13].
3. **HTML + CSS Modal Pop-Up Window:** Dynamically generating a custom overlay and warning list dialog when validation errors occur[cite: 9, 14].
